# Database Folder

This folder contains the datasets used to develop the Ontario Gym Opportunity Dashboard.

## Dataset groups

| File | Description |
|---|---|
| `dataset-a-da-demographics.csv` | Dissemination-area demographic records used as the base census layer. |
| `dataset-a-raw-demographic-fact.csv` | Larger raw demographic fact table used during census preparation. |
| `dataset-a-market-zone-da-mapping.csv` | Mapping from dissemination areas into project-defined market zones. |
| `dataset-a-market-zone-demographics.csv` | Aggregated market-zone demographic output. |
| `dataset-b-market-zone-demographics.csv` | Final dashboard demographic dataset by market zone. |
| `dataset-c-final-gym-locations.csv` | Final gym location and competitor records. |
| `dataset-d-market-zone-competition-summary.csv` | Market-zone gym supply and competition summary. |
| `dataset-e-top-gym-websites.csv` | Top gym brand website/reference list. |
| `dataset-f-amenities-fees-links.csv` | Amenity and fee-source link tracking. |
| `dataset-g-pricing-pages.csv` | Pricing-page availability research. |
| `dataset-h-official-fee-research.csv` | Official fee research fields used during fee comparison. |
| `dataset-i-monthly-fee-summary.csv` | Monthly fee summary used in the pricing comparison chart. |
| `dataset-j-brand-fees-amenities-manual.csv` | Manual brand-level amenities and fees comparison table. |
| `master-analysis-decision-funnel.csv` | Combined decision-funnel analysis file used to rank opportunities. |
| `top6-zone-competitor-fee-analysis.csv` | Top-zone competitor and fee comparison data. |
| `fresh-crossmatch-audit-summary.csv` | Fresh cross-match audit summary. |
| `final-gym-dataset-audit-log.csv` | Final gym dataset audit log. |
| `final-fresh-crossmatched-gym-location-database.xlsx` | Final Excel workbook package. |

## Data limitations

Market zones are project-defined analytical groupings, not official municipal boundaries. Gym competitor information, ratings, pricing, and amenities may change and should be re-verified before any real investment decision.
