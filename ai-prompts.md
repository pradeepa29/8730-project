# AI Use Statement and Prompt Appendix

## AI use acknowledgement

Generative AI was used as a project-support tool for planning, structuring, drafting, formatting, and improving the Ontario gym location analytics project. AI assisted with dataset design, dashboard layout, scoring-method explanation, report drafting, presentation structure, and quality-control checklists.

AI was not used as an authoritative factual source. Factual claims in the final submission should be supported by cited sources such as Statistics Canada, official gym websites/location pages, SerpApi/Google Maps-derived location and review outputs, OpenStreetMap/Nominatim geocoding outputs, and the project datasets.

The project owner remains responsible for verifying the accuracy of the datasets, citations, recommendations, and final submitted work.

## Example prompts used

The following prompts summarize the AI interactions used during project development:

1. “I proposed a gym site-selection solution and received feedback that I need better dataset description, citations, larger dataset size, and AI-use acknowledgement. Give me a step-by-step framework.”
2. “Create a database structure with multiple comparison variables, including area variables such as municipality, age group, income, and gym variables such as amenities, 24/7 service, and services provided.”
3. “I want the dashboard to allow searching any municipality or area, such as Windsor East or West, instead of only municipality-level ranking.”
4. “Create a uniform analysis system for 12 Ontario municipalities using market zones rather than only full municipalities.”
5. “Create Dataset B first for demographics, then Dataset C for gyms and Dataset D for market-zone summary.”
6. “Add gym reviews, ratings, services, amenities, and verification status.”
7. “Use SerpApi to cross-check gym locations and ratings.”
8. “Create a regional manager dashboard that shows whether a zone is a good spot to open a new club.”
9. “Add map, approximate coverage, competitor addresses, amenities, monthly prices, and a separate monthly price comparison graph.”
10. “Create presentation slides that use the dashboard interpretation to compare top six zones and then recommend the top three zones.”
11. “Use dashboard screenshots/data directly in the PowerPoint, including opportunity ranking, demand-vs-supply, selected zone cards, competitor table, and pricing comparison.”
12. “Build everything required by the BSMM-8730 assignment PDF.”

## Responsible-use notes

- AI-generated text was reviewed and adapted for the project context.
- Dataset values should be checked against the supplied workbooks before submission.
- Any factual claim about population, income, location count, reviews, pricing, or amenities should be tied to a cited dataset or official/source URL.
- The scoring model is a screening model and should not be presented as a final real-estate decision model.
